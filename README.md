# Small Talk, Big Harvest

An AI hotline that helps farmers diagnose a sick plant: from any phone, by voice in Hindi, without a data bundle.
Hack-Nation × World Bank · Small AI for Development · Agriculture track.

Scroll-driven 3D website (Three.js, GSAP ScrollTrigger, Lenis). All dependencies are vendored, so it runs offline.

## Run

```bash
python3 -m http.server 8770
```

Then open http://localhost:8770/

- `index.html` – main site (clay-miniature islands, scroll story)
- `hotline.html` – alternative design: feature-phone LCD
- `tour.html` – first version: click-through island tour

Keys: `1`–`9` jump to chapters, `#` to the end, `M` toggles key tones. Deep links: `#c05`.

Numbers marked "example" are illustrative.
